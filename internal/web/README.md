# Web UI

This package contains a simple web UI for the project.
It is not intended to be a core part of the project and is only meant for testing and demonstration purposes.
To run the web UI, start the server by running the following command from the root of the project:

```bash
go run ./cmd/cli/main.go --serve :8080
```

Then, open your web browser and navigate to `http://localhost:8080`.
